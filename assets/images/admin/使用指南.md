# Decap CMS 使用指南

## 🚀 快速开始

### 本地开发

1. **安装依赖**（如果还没有）：
   ```bash
   npm install -g decap-cms-proxy-server
   ```

2. **启动本地代理服务器**（新开一个终端）：
   ```bash
   npx decap-cms-proxy-server
   ```
   或者：
   ```bash
   npm install -g decap-cms-proxy-server
   decap-cms-proxy-server
   ```

3. **启动 Hugo 服务器**：
   ```bash
   hugo serve
   ```

4. **访问管理后台**：
   打开浏览器访问：`http://localhost:1313/admin/`

5. **开始编辑**：
   - 所有更改会直接保存到本地文件系统
   - 无需 Git 认证
   - 可以立即看到效果

### Git 部署

1. **确保代码已提交**：
   ```bash
   git add .
   git commit -m "Update content"
   git push
   ```

2. **如果使用 Netlify**：
   - 在 Netlify 控制台启用 **Identity** 服务
   - 启用 **Git Gateway**
   - 访问 `https://你的域名/admin/` 进行登录

3. **访问管理后台**：
   - 生产环境：`https://你的域名/admin/`
   - 使用 GitHub/GitLab 账号登录
   - 更改会通过 Git Gateway 提交到仓库

## 📝 创建新文章

1. 在管理后台点击 **"New Post"**
2. 填写文章信息：
   - **标题**：文章标题
   - **发布日期**：自动填充当前时间，可修改
   - **草稿**：是否作为草稿保存
   - **标签**：从下拉列表选择（支持多选）
   - **分类**：选择分类（作品/回忆/心里话）
   - **预览图片**：可选，填写图片路径如 `/2/文件1.jpg`
   - **启用评论**：是否允许评论
   - **正文**：使用 Markdown 编辑

3. 点击 **"Save"** 保存

## 🖼️ 上传和管理图片

### 方法一：通过 CMS 上传
1. 在编辑器中点击图片按钮
2. 选择或拖拽图片上传
3. 图片会自动保存到 `static` 目录
4. 使用生成的路径插入图片

### 方法二：手动上传
1. 将图片放到 `static/文件夹名/` 目录
2. 在 Markdown 中使用：`![](/文件夹名/文件名.jpg)`

## 📋 编辑现有文章

1. 在文章列表中点击要编辑的文章
2. 修改内容
3. 点击 **"Save"** 保存更改

## ⚙️ 配置说明

### 当前配置（`config.yml`）

- **后端模式**：`git-gateway`（生产环境）+ `local_backend: true`（本地开发）
- **媒体文件夹**：`static`
- **内容格式**：TOML 前置参数（`+++`）
- **文章位置**：`content/posts/`

### 标签和分类

**标签选项**：
- 作品、文章、回忆、心里话
- 文艺、清新、电影感、日系、小清新
- 法式、暗黑、情绪、抽象、大海
- 糖水、职业生涯、自我
- CNU编辑精选、CNU最热、故事感、夏天

**分类选项**：
- 作品
- 回忆
- 心里话

## 🔧 故障排除

### 本地开发无法访问
- 确保 `decap-cms-proxy-server` 正在运行
- 检查 Hugo 服务器是否在运行
- 确认访问的是 `http://localhost:1313/admin/`

### 部署后无法登录
- 检查 Netlify Identity 是否已启用
- 确认 Git Gateway 已启用
- 检查是否已邀请你的邮箱

### 保存失败
- 本地开发：检查文件权限
- Git 部署：检查 Git Gateway 配置
- 查看浏览器控制台的错误信息

## 💡 使用技巧

1. **批量上传图片**：可以一次性选择多张图片上传
2. **Markdown 预览**：编辑时可以看到实时预览
3. **草稿模式**：保存为草稿，完成后取消草稿状态
4. **图片路径**：使用相对路径，如 `/2/文件1.jpg`（从 static 目录开始）
