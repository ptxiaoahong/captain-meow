# 图片上传到 CloudBase 使用说明

## 前置条件

### 1. 安装依赖
```bash
cd "/Users/hongshize/猫猫船长个人网站"
npm install
```

### 2. 安装云开发 CLI
```bash
npm install -g @cloudbase/cli
```

或者使用项目本地安装：
```bash
npm install
```

### 3. 登录云开发 CLI

运行登录命令：
```bash
tcb login
```

这会打开浏览器，使用微信扫码登录即可。登录一次后，后续上传会自动使用已保存的认证信息。

## 使用步骤

### 1. 压缩图片
```bash
npm run compress-images
```

### 2. 上传图片到云存储
```bash
npm run upload-images
```

### 3. 一键部署（压缩 + 上传 + 转换数据）
```bash
npm run deploy-miniprogram
```

## 脚本功能

- ✅ 自动上传三种尺寸的图片（缩略图、中等图、原图）
- ✅ 跳过已存在的文件（避免重复上传）
- ✅ 显示上传进度
- ✅ 支持并发上传（默认5个并发）
- ✅ 错误处理和重试提示

## 上传目录结构

上传后的云存储目录结构：
```
images/
├── thumbnails/
│   ├── 11/文件-1.jpg
│   └── ...
├── medium/
│   ├── 11/文件-1.jpg
│   └── ...
└── original/
    ├── 11/文件-1.jpg
    └── ...
```

## 注意事项

1. **登录状态**：CLI 登录后，认证信息会保存在本地，无需每次登录
2. **上传速度**：大量图片上传可能需要较长时间
3. **网络要求**：需要稳定的网络连接
4. **费用**：云存储有免费额度，超出后会产生费用
5. **重复上传**：CLI 会自动跳过已存在的文件

## 常见问题

**Q: 上传失败怎么办？**
A: 检查网络连接和密钥配置，失败的文件可以重新运行脚本上传（会自动跳过已存在的文件）

**Q: 如何只上传新增的图片？**
A: 脚本默认会跳过已存在的文件，只上传新文件

**Q: 可以调整并发数吗？**
A: 修改 `upload-to-cloudbase.js` 中的 `concurrent` 参数（默认5）
