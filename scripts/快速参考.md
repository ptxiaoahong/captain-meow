# 文章更新快速参考

## 🆕 添加新文章（最快方式）

```bash
# 1. 修改 scripts/create-new-post.js 配置
#    - SOURCE_DIR: 图片目录
#    - POST_CONFIG: 标题、分类、标签、目录编号

# 2. 运行脚本
cd /Users/hongshize/猫猫船长个人网站
node scripts/create-new-post.js

# 3. 推送 Hugo
hugo --gc --minify && git add . && git commit -m "添加新文章" && git push

# 4. 上传图片到云存储（控制台）
#    - static/compressed/medium/目录编号/ → images/medium/目录编号/
#    - static/compressed/share/目录编号/ → images/share/目录编号/
#    - static/compressed/original/目录编号/ → images/original/目录编号/

# 5. 导入数据库（控制台）
#    - 使用: 猫猫船长小程序/data/posts-cloudbase-clean.json
#    - 格式: JSON Lines
```

- **Hugo 文章**: `content/posts/分类/文章标题.md`
- **原始图片**: `static/目录编号/`
