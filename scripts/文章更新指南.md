## 🆕 添加新文章

### 方法一：使用自动化脚本（推荐）

适用于：**新文章，有原始图片文件**

#### 步骤 1：准备图片

将新文章的原始图片放在一个目录中，例如：
```
/Volumes/移动硬盘/2025.11.6 厦门 小锦/成片/noon
```

#### 步骤 2：修改脚本配置

编辑 `scripts/create-new-post.js`：

```javascript
// 配置
const SOURCE_DIR = '/Volumes/移动硬盘/你的图片目录'; // 修改为你的图片目录
const POST_CONFIG = {
  title: '文章标题',           // 修改为你的文章标题
  category: '作品',            // 修改分类：作品/回忆/心里话
  tags: ['作品', '文艺', '清新'], // 修改标签
  date: new Date().toISOString().split('T')[0], // 自动使用今天日期
  dirNumber: 16                // 修改为下一个目录编号（当前最大是15）
};
```

#### 步骤 3：运行脚本

```bash
cd /Users/hongshize/猫猫船长个人网站
node scripts/create-new-post.js
```

脚本会自动：
- ✅ 压缩图片（生成 medium、share、original 三种尺寸）
- ✅ 创建 Hugo Markdown 文件
- ✅ 更新 `posts.json`
- ✅ 生成 `posts-cloudbase-clean.json`（用于增量导入）

#### 步骤 4：推送到 Hugo 网站

```bash
cd /Users/hongshize/猫猫船长个人网站
hugo --gc --minify
git add .
git commit -m "添加新文章: 文章标题"
git push
```

#### 步骤 5：上传图片到云存储

1. 打开云开发控制台
2. 进入"云存储"
3. 上传以下目录的图片：
   - `static/compressed/medium/目录编号/` → `images/medium/目录编号/`
   - `static/compressed/share/目录编号/` → `images/share/目录编号/`
   - `static/compressed/original/目录编号/` → `images/original/目录编号/`

#### 步骤 6：导入数据库

1. 打开云开发控制台
2. 进入"数据库" → "posts" 集合
3. 点击"导入"
4. 选择 `猫猫船长小程序/data/posts-cloudbase-clean.json`
5. 选择"JSON Lines"格式
6. 点击"导入"

### 方法二：手动添加

适用于：**只有少量图片或特殊需求**

#### 步骤 1：压缩图片

```bash
cd /Users/hongshize/猫猫船长个人网站
node scripts/compress-images.js
```

这会为 `static/` 目录下的所有图片生成压缩版本。

#### 步骤 2：创建 Hugo 文章

在 `content/posts/分类/` 目录下创建 Markdown 文件，例如：

```markdown
+++
date = '2025-12-15T16:11:24+08:00'
draft = false
title = '文章标题'
tags = ["作品","文艺","清新"]
categories = ["作品"]
featuredImagePreview = ""
comment= true
+++
![](/目录编号/文件-1.jpg) 
<!--more-->
![](/目录编号/文件-2.jpg)
![](/目录编号/文件-3.jpg)
```

#### 步骤 3：更新 posts.json

在 `猫猫船长小程序/data/posts.json` 中添加新文章：

```json
{
  "id": "20251215-文章标题-随机字符串",
  "title": "文章标题",
  "category": "作品",
  "tags": ["作品", "文艺", "清新"],
  "images": [
    {
      "medium": "medium/目录编号/文件-1.jpg",
      "share": "share/目录编号/文件-1.jpg",
      "original": "original/目录编号/文件-1.jpg"
    }
  ],
  "description": "文章描述（可选）",
  "date": "2025-12-15"
}
```

#### 步骤 4：生成云数据库格式

```bash
cd /Users/hongshize/猫猫船长个人网站
node scripts/prepare-cloudbase-data.js
```

这会生成 `posts-cloudbase.json` 文件。

#### 步骤 5：上传和导入

按照"方法一"的步骤 5 和 6 操作。

## ✏️ 更新现有文章

### 更新文章内容

1. 直接编辑 Hugo Markdown 文件：`content/posts/分类/文章标题.md`
2. 推送到网站：
   ```bash
   cd /Users/hongshize/猫猫船长个人网站
   hugo --gc --minify
   git add .
   git commit -m "更新文章: 文章标题"
   git push
   ```

### 更新文章图片

1. 替换 `static/目录编号/` 中的图片文件
2. 重新压缩图片：
   ```bash
   cd /Users/hongshize/猫猫船长个人网站
   node scripts/compress-images.js
   ```
3. 更新 `posts.json` 中的图片路径（如果需要）
4. 重新生成云数据库格式：
   ```bash
   node scripts/prepare-cloudbase-data.js
   ```
5. 上传新图片到云存储（覆盖旧文件）
6. 导入更新的数据库（全量导入 `posts-cloudbase.json`）

### 更新文章元数据（标题、分类、标签等）

1. 编辑 `posts.json`，修改对应文章的字段
2. 编辑 Hugo Markdown 文件的 front matter
3. 重新生成云数据库格式：
   ```bash
   node scripts/prepare-cloudbase-data.js
   ```
4. 导入更新的数据库

## 📤 上传图片到云存储

### 方式一：通过控制台上传（推荐）

1. 打开[云开发控制台](https://console.cloud.tencent.com/tcb)
2. 进入"云存储"
3. 进入对应的目录（如 `images/medium/15/`）
4. 点击"上传文件"
5. 选择本地文件上传

### 方式二：使用命令行工具

```bash
# 安装云开发 CLI
npm install -g @cloudbase/cli

# 登录
tcb login

# 上传单个目录
tcb storage upload static/compressed/medium/15 images/medium/15 --envId 你的环境ID

# 上传所有 medium 图片
tcb storage upload static/compressed/medium images/medium --envId 你的环境ID
```

## 💾 更新数据库

### 增量导入（推荐）

适用于：**只添加新文章**

1. 使用 `posts-cloudbase-clean.json` 文件
2. 在云开发控制台 → 数据库 → posts 集合
3. 点击"导入"
4. 选择 `posts-cloudbase-clean.json`
5. 选择"JSON Lines"格式
6. 点击"导入"

**注意**：云数据库会自动去重（基于 `_id`），所以可以重复导入。

### 全量导入

适用于：**更新现有文章或大量修改**

1. 运行脚本生成全量数据：
   ```bash
   cd /Users/hongshize/猫猫船长个人网站
   node scripts/prepare-cloudbase-data.js
   ```
2. 在云开发控制台 → 数据库 → posts 集合
3. **先清空集合**（谨慎操作！）
4. 点击"导入"
5. 选择 `posts-cloudbase.json`
6. 选择"JSON Lines"格式
7. 点击"导入"

## 🔧 工具脚本说明

### `create-new-post.js`

**功能**：自动化创建新文章

**使用场景**：
- 添加新文章
- 有原始图片文件

**输出**：
- Hugo Markdown 文件
- 压缩后的图片（medium、share、original）
- 更新的 `posts.json`
- 生成的 `posts-cloudbase-clean.json`

### `compress-images.js`

**功能**：压缩所有图片

**使用场景**：
- 批量压缩图片
- 更新现有图片

**输出**：
- `static/compressed/medium/` - 中等尺寸（1200px）
- `static/compressed/share/` - 分享尺寸（1000×800，5:4）
- `static/compressed/original/` - 原图压缩（95% 质量）

### `prepare-cloudbase-data.js`

**功能**：生成云数据库导入格式

**使用场景**：
- 更新数据库前
- 修改文章数据后

**输入**：`posts.json`
**输出**：`posts-cloudbase.json`（JSON Lines 格式）

### `generate-share-images.js`

**功能**：为所有文章的封面图生成 share 尺寸

**使用场景**：
- 批量生成 share 图片
- 补充缺失的 share 图片

**输出**：`static/compressed/share/` 目录下的图片

### `update-posts-with-share.js`

**功能**：更新 `posts.json`，添加 share 字段

**使用场景**：
- 为旧文章添加 share 字段
- 统一数据格式

## ❓ 常见问题

### Q1: 如何确定下一个目录编号？

查看 `static/` 目录下最大的数字目录，加 1 即可。

例如：当前最大是 `15`，下一个就是 `16`。

### Q2: 图片上传失败怎么办？

1. 检查文件大小（建议单张不超过 5MB）
2. 检查文件格式（支持 JPG、PNG）
3. 检查云存储空间是否充足
4. 尝试分批上传

### Q3: 数据库导入失败怎么办？

1. 检查文件格式是否为 JSON Lines（每行一个 JSON 对象）
2. 检查 JSON 格式是否正确
3. 检查是否有重复的 `_id`
4. 尝试先清空集合再导入

### Q4: 如何更新封面图？

封面图是每篇文章的第一张图片。如果要更换封面：

1. 在 `posts.json` 中将新图片移到 `images` 数组的第一位
2. 重新生成云数据库格式
3. 导入数据库

### Q5: share 图片没有生成怎么办？

运行脚本生成：

```bash
cd /Users/hongshize/猫猫船长个人网站
node scripts/generate-share-images.js
```

### Q6: 如何删除文章？

1. 删除 Hugo Markdown 文件
2. 从 `posts.json` 中删除对应文章
3. 重新生成云数据库格式
4. 在云开发控制台删除对应的数据库记录

### Q7: 图片路径格式是什么？

**本地格式**（posts.json）：
```json
{
  "medium": "medium/15/文件-1.jpg",
  "share": "share/15/文件-1.jpg",
  "original": "original/15/文件-1.jpg"
}
```

**云存储格式**（posts-cloudbase.json）：
```json
{
  "medium": "images/medium/15/文件-1.jpg",
  "share": "images/share/15/文件-1.jpg",
  "original": "images/original/15/文件-1.jpg"
}
```

注意：云存储格式需要 `images/` 前缀。
